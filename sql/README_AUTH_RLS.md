# عبيد — Auth/RLS rollout

## الترتيب الآمن
1. لا تشغّل `real_auth_migration_and_rls.sql` القديم.
2. راجع وشغّل `auth_rls_preflight.sql` أولاً (قراءة فقط).
3. تأكد أن حسابات Supabase Auth مرتبطة بـ `public.users.auth_uid`.
4. طبّق `auth_rls_safe_full.sql` بعد مراجعة النتيجة.
5. طبّق `security_hardening_v2.sql` فقط بعد التأكد من توافقه مع السياسات الجديدة.
6. اختبر تسجيل الدخول، إنشاء الطلب، قبول الفني، تتبع الحالة، إنشاء الفاتورة وعزل الفنيين.

## مهم
- هذا الترحيل لا ينشئ مستخدمي Supabase Auth تلقائياً.
- لا يحذف البيانات ولا يحذف `pass_word`.
- لا يغيّر واجهة التطبيق.
- لا يتم تشغيل أي SQL إنتاجي من هذا الملف تلقائياً.
