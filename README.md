# تطبيق عبيد للصيانة — بناء APK حقيقي من الهاتف فقط (بدون كمبيوتر، بدون متاجر)

هذا الدليل يبني لك ملف APK حقيقي قابل للتثبيت مباشرة على جوالك، بدون Google
Play، بدون Mac، وبدون أي كمبيوتر — البناء يحدث بالكامل على سيرفرات GitHub
المجانية، وأنت فقط ترفع الملفات وتضغط زر "تشغيل" من متصفح جوالك.

الإشعارات في هذا التطبيق **حقيقية 100%** عبر Firebase، وبما أنه تطبيق مُصرَّف
(native APK) وليس صفحة ويب، فالضغط على الإشعار **يفتح التطبيق نفسه دائمًا**
ولا يفتح كروم أو أي متصفح إطلاقًا.

---

## الخطوات (كلها من متصفح الجوال)

### 1) أنشئ حساب GitHub مجاني
من https://github.com/signup (إن لم يكن عندك حساب).

### 2) أنشئ مستودع (Repository) جديد
من الصفحة الرئيسية اضغط **+** ثم **New repository**
- الاسم: `obied-app`
- اجعله **Private** (خاص) — مهم لأنه سيحتوي إعدادات Firebase لاحقًا
- اضغط **Create repository**

### 3) ارفع ملفات المشروع
داخل المستودع: **Add file → Upload files**
ارفع هذه الملفات (موجودة في نفس المجلد اللي حمّلته):
- `index.html`
- `package.json`
- `capacitor.config.json`
- `.gitignore`

ثم أنشئ مجلد **assets** (بالضبط بهذا الاسم) وارفع بداخله 4 الصور:
- `assets/icon.png`
- `assets/icon-foreground.png`
- `assets/icon-background.png`
- `assets/splash.png`

(في GitHub: اضغط Upload files، ثم بالسحب أو الاختيار حدد الصور الأربعة معاً وهي داخل مجلد
باسم assets على جهازك — سيرفعها GitHub بنفس المسار تلقائياً. إذا ما ظهر خيار
رفع مجلد، ارفع كل صورة عبر "Create new file" واكتب في اسم الملف
`assets/icon.png` مثلاً، ثم بدّل نوع الملف لاحقاً أو استخدم Upload files
العادي فهو يدعم اختيار عدة ملفات دفعة واحدة لنفس المسار إذا كانت جميعها
داخل مجلد assets عند اختيارها من مدير ملفات جوالك).

اسم التطبيق الظاهر تحت الأيقونة على جوالك الآن: **UBEYD**
الأيقونة: دائرة بيضاء بحرف U أزرق ضمن خلفية متدرجة زرقاء بلمسة كهرمانية،
بنفس هوية ألوان الموقع.

ثم اضغط **Commit changes**.

### 4) أضف ملف البناء (workflow)
داخل المستودع: **Add file → Create new file**
في خانة اسم الملف اكتب بالضبط (GitHub سينشئ المجلدات تلقائيًا من الشرطات):
```
.github/workflows/build-android.yml
```
افتح الملف `build-android.yml` من الملف اللي حمّلته، انسخ محتواه بالكامل،
والصقه في نفس الصندوق، ثم **Commit changes**.

### 5) أنشئ مشروع Firebase (5 دقائق، من المتصفح)
1. افتح https://console.firebase.google.com
2. **Add project** → أعطه أي اسم → أكمل الإنشاء
3. من الصفحة الرئيسية اضغط أيقونة **Android** لإضافة تطبيق أندرويد
4. **Android package name** يجب أن يكون بالضبط:
   ```
   com.obied.maintenance
   ```
5. أكمل التسجيل، ثم حمّل ملف **google-services.json** (سينزل على جوالك)
6. افتحه بأي تطبيق ملاحظات/محرر نصوص على جوالك وانسخ **محتواه بالكامل**
   (نص JSON)

### 6) أضف محتوى الملف كـ "Secret" سري في GitHub
داخل مستودعك: **Settings → Secrets and variables → Actions → New repository secret**
- Name: `GOOGLE_SERVICES_JSON`
- Secret: الصق محتوى ملف google-services.json كاملاً
- **Add secret**

### 7) شغّل البناء
اذهب لتبويب **Actions** أعلى المستودع → اختر **Build Android APK** من القائمة
اليسرى → اضغط **Run workflow** (زر أخضر) → **Run workflow** للتأكيد.

انتظر 3-6 دقائق (سترى دائرة صفراء تتحول لعلامة ✅ خضراء عند الانتهاء).

### 8) نزّل التطبيق وثبّته
اضغط على البناء المكتمل (✅) → انزل لأسفل لقسم **Artifacts** → اضغط
**obied-app-apk** لتنزيله (سيأتي كملف zip يحتوي APK بداخله).
افتح ملف الـ zip من مدير الملفات، استخرج ملف `app-debug.apk`، اضغط عليه
للتثبيت. أول مرة سيطلب منك أندرويد تفعيل **"السماح بالتثبيت من هذا المصدر"**
— وافق، ثم أكمل التثبيت.

🎉 التطبيق الآن مثبّت فعليًا على جوالك بأيقونته الخاصة، بدون متجر، بدون كمبيوتر.

## تفعيل استقبال الإشعارات الحقيقية من السيرفر
هذا الجزء اختياري ولاحق — تقدر تستخدم التطبيق الآن وتضيفه متى ما جهزت وقتًا:
كل التفاصيل (دالة الإرسال + جدول قاعدة البيانات) موجودة في:
- `supabase-functions/send-push/index.ts`
- `sql/push_setup.sql`

الأوامر المطلوبة هناك (`npx supabase ...`) تحتاج طرفية (Terminal)، وهذا الجزء
فعليًا أسهل تنفيذه لاحقًا من أي جهاز كمبيوتر تستعيره لمرة واحدة (10 دقائق)،
أو من تطبيق طرفية سحابية على الجوال إن رغبت — أخبرني وأدلّك على الطريقة
بالتفصيل.

## ملاحظات مهمة
- **iOS/آيفون**: بناء تطبيق آيفون بدون رفعه للمتجر يتطلب من آبل نفسها (وليس
  مني) حساب مطوّر مدفوع (99$/سنة) على الأقل، بالإضافة لجهاز Mac ولو لمرة
  واحدة أو خدمة بناء سحابية مدفوعة. هذا قيد من Apple لا يوجد له حل مجاني
  حتى لو البناء تم سحابيًا. أخبرني إذا تريد نتابع فيه لاحقًا.
- APK الحالي **debug** (للاستخدام الشخصي المباشر) — يعمل تمامًا بكل الميزات،
  لكنه غير موقّع بمفتاح نشر رسمي. إذا قررت لاحقًا رفعه على Google Play،
  نحتاج خطوة توقيع إضافية بسيطة سأجهزها لك وقتها.
- إذا فشلت خطوة **Build debug APK** في السجلّ (Log)، انسخ لي رسالة الخطأ
  وأرسلها هنا وأصلحها لك فورًا — تفاصيل إعداد Gradle/Firebase أحيانًا تحتاج
  تعديل بسيط حسب نسخة الأدوات وقت التشغيل.
